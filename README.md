# aktapokus-kesif

TYT/AYT yolculuğu için ezber değil keşif. Statik web uygulaması: sunucu, hesap, izleyici yok; ilerleme yalnızca tarayıcıda.

**Çalıştırma:** `python -m http.server 8123` ile bu klasörü sun, `http://127.0.0.1:8123` aç. (Bilgisayar, tablet, telefon tarayıcısı.)

**Yapı:** `data/` içinde ders içerikleri (`mat-limit.js`, `tr-paragraf.js`), günlük soru havuzu (`gunluk.js`), ders ağırlıkları ve haftalık ritim (`plan.js`). `app.js` hepsini çizer.
