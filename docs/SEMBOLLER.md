# Ortak simgeler ve gösterim (tüm içerik bu kurala uyar)

Öğrenci, sınavda ve okulda gördüğü simgeleri burada da görmeli. Yeni bir ders yazarken harfleri kendin seçme; aşağıdakini kullan.

| Büyüklük | Simge | Birim simgesi |
|---|---|---|
| zaman, an | **t** | **s** (saniye), dk, sa |
| zaman aralığı, değişim | **Δt**, **Δx** (Δ = "değişim") | |
| yol / konum | **s** (konum fonksiyonu **s(t)**) | **m** |
| hız | **v** | **m/s**, km/sa |
| ivme | **a** | m/s² |
| fonksiyon | **f(x)**, **g(x)** | |
| doğru denklemi | **y = ax + b** (a: eğim) | |
| ilişki katsayısı | **r** | |
| gözlem sayısı | **n** | |
| açı | **x**, **θ**, birim **°** | |
| taban | **a** (üstel/log) | |

Kurallar:
- **Birim simgeleri SI'dir:** saniye "s" (sn değil), metre "m", kilogram "kg". Metinde sözcük olarak "saniye" yazılabilir; tablo/eksen/formülde simge kullanılır.
- Fonksiyon adı ile değişken karışmasın: s(t) "t anındaki yol"dur.
- Ondalık ayırıcı **virgül** (3,5); bin ayırıcı boşluk veya nokta tutarlı olsun.
- Her yeni derste ilk kez geçen simge, yanında sözcükle tanıtılır (Δt = ölçüm aralığı).
- Dersin diline "h" gibi anlamsız harf getirme; sınav kitaplarında genel simge ne ise onu kullan.

- Fizikte konum/yol **x** (Δx yer değiştirme), hız **v**, ivme **a**, zaman **t**; matematikte konum fonksiyonu s(t) kullanılabilir. Saniye birimi her yerde **s**.
